# ContextLens 1.0 설치·업데이트

기존 프로토타입의 인식 입력, 그룹 검색·검증, 블러 카드, 호출 한도를 수정한 버전입니다. 실제 Instagram 영상에서의 인식률 향상 수치는 아직 측정하지 않았습니다.

## 기존 설치를 업데이트할 때

1. 기존 프로젝트를 백업합니다. **기존 `bridge/.env`는 그대로 보관**합니다. 새 ZIP에는 실제 API 키가 포함되어 있지 않습니다.
2. 새 프로젝트 파일을 기존 프로젝트 폴더에 복사합니다. `extension/`도 기존 확장 프로그램이 읽는 폴더에 덮어씁니다. `bridge/.env.example`을 기존 `.env`에 덮어쓰지 않습니다.
3. 실행 중인 이전 bridge를 종료하고 프로젝트 최상위 폴더에서 `npm run bridge`를 실행합니다. Node.js 22.13 이상이 필요합니다. 확장 프로그램과 bridge 자체는 `npm install` 없이 실행됩니다.
4. `chrome://extensions`에서 기존 ContextLens의 **Reload**를 누릅니다. 기존 항목을 삭제하지 않아야 기존 확장 ID와 저장된 카운트가 유지됩니다.
5. 팝업에서 터미널의 pairing token을 입력합니다. AI 인식과 프레임 공유를 켜고 저장한 뒤 Instagram 탭을 새로고침합니다. N 설정은 기존처럼 2–25입니다.

기존 `.env`가 `DAILY_META_LIMIT=200`이면 이제 서버가 200을 그대로 사용합니다. 팝업 진단에 남은 호출 수가 표시됩니다. 200은 처리 영상 수가 아닌 **실제 모델 요청 시도 수**입니다. 일반적인 새 영상 비교에는 관찰과 검증으로 두 번의 요청이 들 수 있습니다. 로컬 한도는 UTC 자정에 초기화되고 bridge 재시작으로 사라지지 않습니다.

## 새로 설치할 때

`bridge/.env.example`을 `bridge/.env`로 복사해 본인의 Meta API 키를 넣습니다. 터미널에서 `npm run bridge`를 실행하고, Chrome 개발자 모드의 Load unpacked로 `extension/`을 선택합니다. 팝업에는 API 키 대신 터미널에 나온 pairing token을 입력합니다.

## 무엇을 고쳤는가

- 프레임: 최대 3장·240px에서 최대 8장·긴 변 512px로 변경했습니다. 실제 재생 시각을 함께 전달하고 화면에 보이는 동안만 캡처합니다. 스크롤 전에 3장 이상 관찰했다면 수집한 자료로 분석을 마칩니다.
- 인식: 현재 영상 설명을 먼저 만들고, 그 설명으로 최대 500개 저장 그룹을 검색한 뒤 동일 현상을 별도 검증합니다. 한국어 별칭·OCR·구체적 행동·대상을 검색에 활용합니다.
- 오인식 방지: 같은 카테고리, 같은 음악, 같은 이름만으로 합치던 경로를 제거했습니다. 검증이 불확실하면 횟수를 올리지 않습니다. 이 보수적 정책의 미탐·지연 영향도 실제 자료로 측정해야 합니다.
- 버튼: Instagram DOM 밖의 Shadow DOM과 별도 표시 레이어로 옮겼습니다. 실제 Instagram에서 Show video, 조사 버튼, 스크롤 후 위치를 확인해야 합니다.
- 카운트: 같은 계정은 한 번만 세며, 저장된 그룹 ID와 계정 기록을 유지합니다. 비슷한 이름의 기존 그룹을 임의로 합치지 않습니다.

## 본인 영상으로 확인하기

1. 새 터미널에서 프로젝트 최상위 폴더로 이동해 `npm run feed`를 실행합니다.
2. `http://127.0.0.1:8765/real.html`을 엽니다.
3. 사용 권한이 있는 영상을 고르고 각 영상의 게시 계정과 캡션을 입력합니다. 계정을 입력하기 전에는 카운트하지 않습니다.
4. 같은 현상의 서로 다른 촬영본 3개와 비슷하지만 다른 영상 1개를 차례로 재생합니다.
5. N에 도달하면 블러·일시정지를 확인하고 Show video와 Investigate in OriginTrace를 누릅니다. OriginTrace는 별도로 실행하고 팝업 URL을 설정해야 합니다.

이 페이지는 영상 전체를 Meta에 보내지 않습니다. 확장 프로그램의 명시적 설정에 따라 프레임과 메타데이터를 보냅니다. 전체 MP4 입력 비교는 `tools/evaluate.cjs --mode video`에 별도로 구현되어 있습니다.

## 현재 확인한 범위

자동 회귀검사 40개와 JavaScript 문법·manifest 검사를 통과했습니다. 실제 Meta API로 합성 상품의 이미지 관찰, 동일 상품 검증, 같은 브랜드의 다른 상품 분리, MP4 입력을 확인했습니다. 이 검사는 실제 Instagram 인식률이 아닙니다.

이 작업 환경에서는 Chromium 다운로드가 정상 파일을 반환하지 않았고, 별도 브라우저가 로컬 테스트 서버에 연결하지 못했습니다. 따라서 포인터·키보드·스크롤 자동 브라우저 검사와 로그인된 Instagram 실기 검증은 완료하지 못했습니다. `npm run test:browser`용 실제 브라우저 검사 코드와 `node tools/browser-fixture.cjs` 수동 확인 화면을 포함했습니다.

검증 기록은 `docs/VALIDATION.md`, A·B의 심사 전략은 `docs/JUDGING_REVIEW_KO.md`, 3분 대본은 `docs/DEMO_EN.md`를 확인하세요. 다음 성능 판단은 실제 평가 영상으로 기존 버전과 같은 조건에서 비교한 뒤 내립니다.
